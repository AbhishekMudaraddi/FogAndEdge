Edge, fog, and cloud — who does what?

Edge simulates 5 sensor types per rack and publishes batches to SQS on a configurable interval (SENSOR_FREQUENCY, DISPATCH_RATE).

Fog (Lambda) consumes each message, derives cooling efficiency and boolean risk flags from the batch, attaches TTL, and writes enriched items to DynamoDB. Check CloudWatch logs for structured JSON lines (event: enrichment_batch) with rack_id, flag_count, and cooling_efficiency.

Cloud (this app) queries DynamoDB, serves the dashboard, computes aggregates and charts in the browser — it does not re-run Lambda logic; it displays fog outputs stored on each reading.
